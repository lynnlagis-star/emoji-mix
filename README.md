# Emoji 混搭工坊

單一 HTML 檔的 Emoji 混搭小工具，用 Chrome 開啟即可使用，無需安裝、無相依套件。

## 玩工具

- 操作版（GitHub Pages）：https://lynnlagis-star.github.io/emoji-mix/
- 程式碼頁：https://github.com/lynnlagis-star/emoji-mix

## 功能

- 基底、頂部配件、中層混搭、底部混搭多層疊加即時預覽
- 背景顏色、透明背景、底部自訂文字
- 隨機混搭、清除配件
- 匯出 512×512 PNG，可插入 Word、PowerPoint、LINE 電腦版
- 複製圖片後可直接到 Gmail、Notion、Discord、Word 按 Ctrl+V 貼上

## 本機使用

1. 下載或複製此儲存庫
2. 用 Chrome 開啟 `index.html`
3. 左側挑選組合，右側即時顯示
4. 按匯出 PNG 或複製圖片分享

## 檔案結構

- `index.html`：工坊主程式，唯一必要的檔案
- `README.md`：本說明文件

## 備註

- 複製圖片需要瀏覽器允許剪貼簿權限，若失敗請改用匯出 PNG
- 歡迎自由混搭與分享
